# How to use this vault

This vault is your notebook. Claude reads it so it keeps context between sessions.

## Working on an app

Start Claude in the app's folder. Each app has its own `CLAUDE.md` that says what the app is, how to run it, and what is next. Claude reads it first.

## The skills

Type these in Claude Code:

- `/kit-daily` starts or reviews today's daily note.
- `/kit-capture` saves a quick thought, link or idea to the Inbox.
- `/kit-new-project` sets up a new project folder with a project note.
- `/kit-eod-flush` ends your session: it saves your work and commits it.
- `/kit-handoff` writes a summary so the next session can pick up where you stopped.
- `/kit-dream` tidies Claude's memory: it merges duplicates and flags old facts.

## Updating the kit

To get the latest version, tell Claude: "update my vault starter kit".
